# HanziCramming

Отдельное приложение для тренировки написания китайских иероглифов.

Проект создан на основе HanziPractice, но развивается независимо. Исходный репозиторий HanziPractice не изменяется.

## Планируемые особенности
- Добавление собственных иероглифов в личный словарь.
- Поиск пиньиня и перевода с возможностью ручного ввода.
- Проверка наличия эталона написания.
- Список ожидания для иероглифов без доступного эталона.
- Локальное хранение словаря и прогресса.
- Освоение иероглифа после 10 успешных полных написаний подряд.

## Технологии
Expo / React Native / TypeScript.
